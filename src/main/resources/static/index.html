Architecture Highlights

Engineering considerations designed for the B.Tech viva voce demonstration.

🛡️ Anti-Cheat Validation

Every score submission is validated server-side within an @Transactional boundary. Spring Boot checks score vs. duration against the game's registered maximum rate per second.

🕹️ Object-Oriented Engine

All games extend GameBase.js, inheriting fixed delta-time loops, High-DPI canvas scaling, automatic pause on tab blur, and unified score persistence hooks.

🔐 Stateless JWT Security

Protected endpoints authenticate requests via HMAC-SHA512 signed JWTs in the Authorization Bearer header, managed by custom Spring Security 6.x filters.
